The KV store that lives in Git.

Strata is a free, self-hosted key-value store. Every write is a commit — versioned, diffable, auditable. No quotas, no lock-in.

Why Strata

  • History is the database. Every PUT and DELETE is a commit you can inspect, diff, or revert.
  • Self-hosted and unlimited. Run on Vercel, Netlify, Docker, Heroku, Render, or plain Node with your own storage.
  • Simple to outgrow. Start fast, keep ownership. If you move to Redis or another database, it’s an export — not a rewrite.

Try it

A small, predictable API. Writes return seq, queued, and persisted so clients know the durability guarantee.

curl -X PUT $URL/kv/welcome -H "Content-Type: application/json" -d '{"value":"hello","ttl":3600}'
{"ok":true,"key":"welcome","seq":43,"queued":false,"persisted":true}

curl $URL/kv/welcome
{"key":"welcome","value":"hello"}

curl $URL/keys
{"keys":["welcome","session:9f2c","flag:beta"]}

curl $URL/health
{"ok":true,"mode":"long","journal":{"seq":43,"pendingOps":0,"snapshotEvery":10}}

How it works

  • Git commits. Each write becomes a commit — grep, audit, and revert with standard tools.
  • Journal + snapshots. One JSON op per change; snapshots consolidate every 10 ops.
  • TTL support. Keys expire on their own for URLs, tokens, and feature flags.
  • Safe by default. Optional API_TOKEN (Bearer auth) and concurrency-safe sequence negotiation.
client ─▶ PUT /kv/x ─▶ journal/000043.json (one commit per op)
    │
    └─ every 10 ops ─▶ snapshot.json ─▶ old journal entries compacted

In the wild

Espresso — a self-hosted Git forge for affordable hardware (ESP32 + SD card) — uses Strata as a Git-backed KV backend in its Node control plane. Session and coordination state is stored through Strata’s REST API, so it runs without a managed database while keeping data versioned and auditable in Git.
