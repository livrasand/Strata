a key-value store whose storage engine is git.

free, self-hosted, unlimited — where redis has usage tiers. setup asks a few more minutes of you than a managed service does, but every write ends up as a commit to your own repository: versioned, diffable, auditable. built to ship your first project on. if it later earns money and outgrows strata, moving to redis or any other database is an export, not a rewrite.

try it — the whole api fits on one screen

curl -X PUT $URL/kv/welcome -H "Content-Type: application/json" -d '{"value":"hello","ttl":3600}'
{"ok":true,"key":"welcome","seq":43,"queued":false,"persisted":true}

curl $URL/kv/welcome
{"key":"welcome","value":"hello"}

curl $URL/keys
{"keys":["welcome","session:9f2c","flag:beta"]}

curl $URL/health
{"ok":true,"mode":"long","journal":{"seq":43,"pendingOps":0,"snapshotEvery":10}}

strata --help

--git
every write is a commit. history is the database — grep it, revert it, audit it.
--journal
one tiny json op appended per change; snapshot consolidates every 10 ops.
--ttl
keys expire on their own. urls, tokens, feature flags.
--token
set API_TOKEN and everything answers 401 without Bearer. timing-safe.
--concurrency
instances racing on the same op renegotiate the seq and retry. no lost writes.
--deps
zero. node ≥ 20.6 is the entire stack.
